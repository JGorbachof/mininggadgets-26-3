# Mining Gadgets - Unofficial Port

Mining Gadgets adds an energy-powered mining laser with configurable mining area, range and upgrades installed through a modification table.

Original project: [Direwolf20-MC/MiningGadgets](https://github.com/Direwolf20-MC/MiningGadgets), version 1.19.3, revision e36293a76d26f2bf5bf535e8483b8e505a890f59.

## Installation
Minecraft 26.3, NeoForge 26.3.0.118, Java 25. Download the mod JAR from [Releases](https://github.com/JGorbachof/mininggadgets-26-3/releases). Install it on client and server. Use a compatible energy charger.

## Alpha status
Headless server tests passed for single-block and 3x3 mining with exact energy consumption, modification table installation/removal, filters and all 27 recipes. Client rendering, real multiplayer, JEI, remaining upgrades and full modpack compatibility are not yet verified.
